# OperationsFlow Toolkit

[![Validate OperationsFlow Toolkit](https://github.com/Codie-Shannon/OperationsFlow-Toolkit/actions/workflows/validate-repository.yml/badge.svg)](https://github.com/Codie-Shannon/OperationsFlow-Toolkit/actions/workflows/validate-repository.yml)
[![Release](https://img.shields.io/github/v/release/Codie-Shannon/OperationsFlow-Toolkit)](https://github.com/Codie-Shannon/OperationsFlow-Toolkit/releases)

A Power BI and Microsoft 365 workflow-design toolkit covering safety,
corrective actions, training compliance, document control, work orders, and
risk reporting.

## Completed Power BI layer

The v1.3 report contains six pages:

1. Executive Overview
2. Corrective Actions
3. Training Compliance
4. Document Control
5. Work Orders
6. Risk Register

The report uses six synthetic CSV datasets and is documented through six
approved screenshots.

## Microsoft 365 design layer

The repository also documents a future implementation using:

- Microsoft Lists or SharePoint Lists;
- Power Apps;
- Power Automate;
- Power BI connected to live list data.

That implementation is **designed but not deployed**. The repository does not
claim a live Microsoft 365 solution.
