# Security Policy

## Supported release

OperationsFlow Toolkit v1.3.0 is the supported portfolio release.

## Reporting

Do not include real incident, training, employee, document, work-order, risk,
tenant, SharePoint, Power Apps, or Power Automate information in a public
issue.

Report a sensitive concern privately to:

`codie.shannon.work@outlook.com`

## Boundary

The Power BI data is synthetic. The Microsoft 365 implementation is a design
package and is not connected to a live tenant.
